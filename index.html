🚀 APP Informática

Proyecto Intermodular · Adrián Fambuena

📋 Descripción del Sistema

Sistema integral de gestión para una tienda de informática que centraliza toda la operativa: inventario, ventas, servicio técnico y gestión de usuarios.

⚙️ Áreas del Sistema

Inventario

Control de productos, marcas y niveles de stock.

Ventas

Registro de transacciones y facturación a clientes.

Servicio Técnico

Seguimiento de reparaciones y asignación de técnicos.

Usuarios

Gestión de roles: Administrador, Vendedor y Técnico.

🛠️ Especificaciones Técnicas

  • Arquitectura Cliente-Servidor
  • Base de datos MySQL (Workbench)
  • Documentación: requisitos, ER y casos de uso
  • Servidor Ubuntu Server 24.04
  • MariaDB / MySQL
  • Red local segura (VLANs)
  • Backups en la nube

📊 Diseño de Datos

Entidades: producto, cliente, tecnico, venta, reparacion

Sistema de consultas SQL para análisis de stock, productividad de técnicos y balance de ventas.
