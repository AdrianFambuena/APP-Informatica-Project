# 🚀 Proyecto Intermodular: APP Informática
### Desarrollado por: Adrián Fambuena Palomo

Este es mi proyecto más completo hasta la fecha, desarrollado como eje central del primer curso de **DAM**. Se trata de un sistema integral de gestión para una tienda de informática, que cubre desde el control de stock hasta la gestión de servicios técnicos y ventas.

---

## 📋 Descripción del Sistema
El sistema permite centralizar la operativa diaria de una tienda tecnológica, gestionando cuatro áreas clave:
* **Inventario:** Control de productos, marcas y niveles de stock.
* **Ventas:** Registro de transacciones y facturación a clientes.
* **Servicio Técnico:** Seguimiento de reparaciones, asignación de técnicos y estados (pendiente, en proceso, terminada).
* **Usuarios:** Gestión de roles (Administrador, Vendedor, Técnico) con diferentes permisos.

---

## 🛠️ Especificaciones Técnicas

### Arquitectura y Software
* **Modelo:** Cliente-Servidor.
* **Base de Datos:** MySQL (Diseñada mediante Workbench).
* **Documentación:** Análisis de requisitos, Diagramas Entidad-Relación y Casos de Uso.

### Infraestructura (Simulada)
* **Servidor:** Ubuntu Server 24.04 con bases de datos MariaDB/MySQL.
* **Red:** Configuración de red local segura (VLANs) y copias de seguridad en la nube.

---

## 📊 Diseño de Datos
El núcleo del proyecto es una base de datos robusta que incluye:
* **Entidades principales:** `producto`, `cliente`, `tecnico`, `venta`, `reparacion`.
* **Consultas e Informes:** Sistema de reportes SQL para detectar stock bajo, productividad de técnicos y balance de ventas diarias.
